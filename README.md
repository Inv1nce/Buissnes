# «На виду» — лендинг агентства

Одностраничный сайт агентства, которое отвечает за то, как локальный бизнес
(кафе, кофейни, небольшие рестораны) в Екатеринбурге выглядит везде, где его
видит клиент — от карточки на картах до вывески у входа.

Статическая страница: HTML + CSS + JS, без сборки и зависимостей.
Достаточно открыть `index.html` или залить папку на любой хостинг
(GitHub Pages, Netlify, Vercel, обычный хостинг по FTP).

## Структура

```
index.html              разметка и весь текст
assets/css/styles.css   стили, mobile-first
assets/js/main.js       меню, анимации, форма, контакты
assets/favicon.svg      иконка
```

## Что нужно поменять перед публикацией

### 1. Контакты — одно место

Откройте `assets/js/main.js`, блок `CONFIG` в самом верху:

```js
var CONFIG = {
  brand:    'На виду',
  telegram: 'na_vidu_ekb',    // ник без @
  whatsapp: '79000000000',    // только цифры, начиная с 7
  phone:    '+7 (900) 000-00-00',
  email:    'hello@navidu.ru'
};
```

Скрипт сам подставит их во все кнопки и ссылки с атрибутом `data-contact`
(шапка, блок контактов, подвал). Руками по странице ходить не нужно.

### 2. Название

Сейчас везде используется рабочее имя **«На виду»**. Если возьмёте другое —
замените по всему проекту:

```bash
grep -rn "На виду" index.html assets/
```

Заменить нужно: `<title>`, og-теги, логотип в шапке, позиционирующую фразу
в hero, подвал и `CONFIG.brand`. Файл `assets/favicon.svg` — просто метка
на карте в фирменном цвете, его менять не обязательно.

### 3. Условия пилота

В блоке «Кейсы» описано предложение для первых партнёров: бесплатный
развёрнутый аудит, особые условия на первые месяцы, взамен — разрешение
показать результат в кейсе. Проверьте формулировки: это обещание клиенту,
и оно должно совпадать с тем, на что вы действительно готовы.

## Как работает форма

Бэкенда нет специально — чтобы сайт можно было положить на статический
хостинг и не заниматься сервером. При отправке формы скрипт:

1. проверяет обязательные поля (имя, заведение, контакт);
2. собирает текст заявки;
3. копирует его в буфер обмена;
4. открывает выбранный мессенджер — WhatsApp с уже подставленным текстом,
   Telegram с открытым чатом (Telegram не умеет подставлять текст в личку,
   поэтому заявка кладётся в буфер и вставляется одним движением).

Если позже появится сервер или сервис вроде Formspree — менять нужно только
обработчик `form.addEventListener('submit', ...)` в `initForm()`.

## Чего на странице намеренно нет

Кейсов, логотипов клиентов и отзывов. Их пока нет в реальности, поэтому
вместо них — честный блок «Кейсов пока нет» с приглашением в пилот.
Когда появятся первые результаты, этот блок заменяется настоящими кейсами.

## Совместимость

- Мобильная вёрстка — базовая, десктоп добавляется медиазапросами
  (`600px` — планшет, `900px` — десктоп).
- Поддерживается `prefers-reduced-motion`, есть стили для печати
  и вариант без JavaScript.
- Размер шрифта в полях формы — 16px, чтобы iOS не зумил страницу при вводе.

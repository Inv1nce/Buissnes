# CA Group — лендинг

Одностраничный сайт агентства, которое оформляет и ведёт карточки бизнеса
в Яндекс Картах и 2ГИС. Екатеринбург, любой бизнес с физической точкой на карте.

Статическая страница: HTML + CSS + JS, без сборки и зависимостей.
Достаточно открыть `index.html` или залить папку на любой хостинг.

## Структура

```
index.html              разметка и весь текст
assets/css/styles.css   стили, mobile-first, тёмная тема
assets/js/main.js       меню, карта в шапке, экспресс-проверка, форма
assets/favicon.svg      иконка
```

## Что нужно поменять перед публикацией

### 1. Контакты — одно место

`assets/js/main.js`, блок `CONFIG` в самом верху:

```js
var CONFIG = {
  brand:    'CA Group',
  telegram: 'cagroup_ekb',    // ник без @
  whatsapp: '79000000000',    // только цифры, начиная с 7
  phone:    '+7 (900) 000-00-00',
  email:    'hello@cagroup.ru'
};
```

Скрипт подставит их во все ссылки с атрибутом `data-contact` — шапка, блок
контактов, подвал. Руками по странице ходить не нужно.

### 2. Условия пилота

В блоке «Кейсы» описано предложение для первых партнёров. Проверьте
формулировки: это обещание клиенту, оно должно совпадать с тем, на что
вы действительно готовы.

## Экспресс-проверка карточки

Интерактивный блок в середине страницы: посетитель отмечает восемь пунктов,
и по ним считается оценка — кольцевая шкала плюс четыре полосы по разделам
(информация, фото, отзывы, активность).

Важно: **это единственные цифры на сайте, и они принадлежат самому посетителю.**
Никакой статистики «мы подняли просмотры на 340%» на странице нет — у агентства
пока нет клиентов, и придумывать такие графики было бы обманом. Когда появятся
реальные результаты пилота, их можно будет добавить отдельным блоком.

Шкала описана прямо на странице как «наша шкала» — восемь пунктов, каждый
даёт 12,5 балла. Пункты и веса лежат в разметке (`data-group`) и в `initCheck()`.

### Цвета графиков

Кольцо одноцветное (лайм), полосы одноцветные (голубой), а вердикт —
текстом. Это не случайно: связка «зелёный / жёлтый / красный» для градаций
не проходит проверку на дальтонизм (при дейтеранопии зелёный и жёлтый
различаются на ΔE 3.7 при норме 8), поэтому смысл несёт подпись, а не цвет.
Если будете менять палитру графиков — держите это в голове.

## Как работает форма

Бэкенда нет специально — чтобы сайт можно было положить на статический
хостинг. Три поля: имя, как найти заведение, способ связи. При отправке скрипт:

1. проверяет, что все три поля заполнены;
2. собирает текст заявки (и подставляет результат экспресс-проверки, если
   посетитель её прошёл);
3. копирует текст в буфер обмена;
4. открывает мессенджер по тому, что человек указал в «способе связи»:
   телефон → WhatsApp с подставленным текстом, `@ник` → Telegram.

Если появится сервер или сервис вроде Formspree — менять нужно только
обработчик `submit` в `initForm()`.

## Оформление

Тёмная «ночная карта»: глубокий индиго `#070B16`, сигнальный лайм `#C4F82A`,
голубой `#35E0FF`, маджента `#FF3D8B`. Одна световая тема, все цвета заданы явно.
Шрифты — Unbounded (заголовки) и Golos Text (текст) с Google Fonts.

В шапке живая canvas-карта: сетка улиц и пульсирующие метки. Анимация
останавливается, когда блок уходит с экрана или вкладка неактивна,
и полностью отключается при `prefers-reduced-motion`.

## Совместимость

- Мобильная вёрстка базовая, десктоп добавляется медиазапросами
  (`620px` — планшет, `940px` — десктоп). Проверено на 320 / 390 / 768 / 1440.
- Поддерживается `prefers-reduced-motion`, есть стили для печати
  и вариант без JavaScript.
- Размер шрифта в полях формы — 16px, чтобы iOS не зумил страницу при вводе.

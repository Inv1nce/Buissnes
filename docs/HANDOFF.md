# Передача проекта

Документ для продолжения работы в новом чате — с Claude или с кем угодно ещё.
Прочитав его, можно включиться в проект без пересказа всей предыстории.

**Как пользоваться:** приложите этот файл в начало нового разговора.
Если собеседник не может открыть репозиторий — скопируйте текст целиком.

---

## 1. Что за проект

**CA Group** — агентство из Екатеринбурга. Одна услуга: оформление и ведение
карточек бизнеса в Яндекс Картах и 2ГИС.

- **Клиенты:** любой бизнес с физической точкой на карте — магазины, салоны,
  клиники, автосервисы, кафе, ПВЗ. Не только общепит.
- **Стадия:** клиентов ещё нет, идёт подготовка. Сайт готов, регламент написан,
  первый тренировочный проект в работе.
- **Чем отличаемся:** личное присутствие в городе (выезжаем и снимаем сами),
  карты как единственная услуга, а не довесок к SMM, ИИ-инструменты внутри работы.

## 3. Что уже сделано

**Сайт-лендинг.** Одностраничный, без сборки: HTML, CSS, JS. Светлая тема
«старая карта»: пергамент `#F6EFE1`, тёмно-коричневый текст `#2B2119`,
красный акцент `#C42B1F`, морская зелень `#1F6F5C`. Шрифты Unbounded
и Golos Text.

Особенности реализации:
- красная пунктирная линия идёт через всю страницу, виляет влево-вправо
  и заканчивается крестиком над формой заявки;
- попугай перелетает между блоками, садится на кромки карточек, осматривается
  и чистит перья; собран из спрайт-листа `assets/parrot.png`;
- в шапке кнопка «Анимация» — видна только тем, у кого движение отключено
  системно, иначе они видят статичную страницу;
- форма из трёх полей без бэкенда: собирает текст и открывает мессенджер.

**Регламент работы с карточкой** — 22 шага плюс раздел про отличия 2ГИС,
таблица замеров и стоп-лист.

**Инструкция по тренировочной пекарне** — готовый текст для каждого поля
Яндекс Бизнеса, меню на 12 позиций, промты для генерации фото товаров.

## 4. Решения, которые уже приняты

Их не нужно обсуждать заново — если только не появилось новых причин.

- **Название:** CA Group.
- **Услуги:** только карты. Фирменный стиль и интерьер отложены — про них
  на сайте ни слова.
- **Логотип:** стеклянная бутылка с пробкой и свёртком карты внутри.
- **Пиратская тема — только визуально.** Бутылка, маршрут, крестик, попугай.
  В текстах пиратской лексики нет, речь деловая.
- **Кейсы не выдумываются.** На сайте честный блок «кейсов пока нет»
  с приглашением в пилот. Никаких фальшивых логотипов, отзывов и процентов.
- **Экспресс-проверка карточки убрана** с сайта по решению владельца.
- **Контакты в коде — заглушки.** Меняются в объекте `CONFIG` в начале
  `assets/js/main.js`.

## 5. Выводы, которые стоили времени

Чтобы не повторять исследование.

**Рынок ИИ-ответов на отзывы уже занят.** Свои сервисы продают TurboMaps,
DailyGrow, SaleSynergy и — главное — сам 2ГИС («Отзывы Про» со встроенными
ИИ-автоответами). Строить на этом продукт значит конкурировать с платформой
на её поле. ИИ должен быть внутренним станком агентства, а не витриной.

**2ГИС встроил ИИ-помощника прямо в карточку** — вкладка «Вопросы», отвечает
за бизнес по данным карточки. Незаполненное поле теперь не просто выглядит
хуже: оно даёт нейросети повод сказать клиенту «информации нет». Это сильнейший
аргумент в продаже наполнения.

**Рейтинг в 2ГИС считается по подтверждённым оценкам** — платформа метит отзыв,
если видит оплату, посещение или бронь. Отзывы сортируются по доверию, а не
по дате. Значит, табличка с QR работает слабо: нужно, чтобы визит проходил
через то, что платформа видит.

**Панораму в Яндексе загрузить нельзя** — кабинет пишет «нет доступных панорам
для данного адреса». Она приходит от съёмочных машин Яндекса. Ранний совет
продавать её как услугу — ошибочный.

**Главный факторы ранжирования** по открытым источникам: полнота профиля
и точная рубрика как база, поведенческие сигналы (звонки, маршруты, время
на карточке) как сильнейший сигнал, свежесть отзывов и ответов весит больше
«застывшей» пятёрки, регулярная активность позволяет обходить конкурента
с более высоким рейтингом.

## 6. Что дальше

Ближайшие шаги, в порядке приоритета.

1. **Решить вопрос с тренировочной карточкой.** Сейчас в Яндекс Бизнесе заведена
   вымышленная пекарня «Булочка» на реальный адрес в селе Амзя. Это риск:
   фейковая организация на живой карте может стоить блокировки аккаунта,
   на котором потом будут вестись реальные клиенты. Рекомендация — тренироваться
   на карточке самой CA Group либо заполнять, но не отправлять на модерацию.
2. **Поменять рубрику** тренировочной карточки с «Кафе» на «Пекарня» — это самое
   дорогое поле, оно решает, по каким запросам карточка участвует в выдаче.
3. **Сгенерировать 12 фото товаров** по промтам из инструкции. Критично:
   все снимки должны выглядеть одной съёмкой — общий блок стиля не меняется.
4. **Заменить заглушки контактов** в `CONFIG`.
5. **Найти первого реального клиента** и снять точку отсчёта до начала работы:
   скриншоты, статистика из кабинета, позиции по 5–10 запросам. Без этого
   через полгода снова не будет кейсов.

## 7. Ограничения, которые нельзя нарушать

- Не выдумывать кейсы, клиентов, отзывы и цифры результатов.
- Не накручивать отзывы и рейтинг, не писать их от лица сотрудников.
- Не обещать клиенту конкретные позиции или рост — формулы ранжирования
  закрыты и меняются.
- Не заявлять фактов о правилах платформ без проверки: они меняются,
  и часть выводов выше может устареть.

---

## 8. Чем какой чат полезен

**Claude Code** нужен, когда работа идёт с репозиторием: правки сайта, запуск
кода, нарезка изображений, коммиты и пуш. Обычный чат этого не может.

**Обычный чат claude.ai** полностью справляется со стратегией, текстами,
промтами, разбором скриншотов карточек и планированием. Для этого достаточно
приложить этот файл.

Если работа снова упрётся в код — вернитесь в Claude Code, репозиторий никуда
не денется.
